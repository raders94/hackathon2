# PORTaI v7 · 유사 기항 검색·큰 효율저하 위험 구현 및 검증

작성: 2026-11-19 · 기존 v6 직관형 Streamlit 대시보드 확장

## 1. 구현 결과

요청한 두 기능을 실제 기항 자료와 학습모형에 연결했습니다. 사이드바에 **유사 기항**, **효율저하 위험**을 독립된 분야로 추가하고 첫 화면에 바로가기를 연결했습니다. 기존 평균 예측·SHAP·모델 B·운영학습 수치는 유지했습니다.

결과 문장 → 크기·색으로 읽는 그림 → 접힌 상세 근거 순으로 표시합니다. 두 새 기능은 조회 조건을 공유하고, 기존 AI 예측 화면의 마지막 조건을 가져올 수 있습니다. 외부 LLM이나 API 키 없이 동작합니다.

**개발한 위험 기능과 실무 효용의 입증은 구분합니다.** 모델은 실제로 학습·보정·평가했지만, 이번 평가에서는 단순 기준보다 우수하지 않았습니다. 화면에 이를 직접 표시하며, 학습 자료가 부족한 입력에서는 확률을 내보내지 않습니다.

## 2. 재사용한 자료와 출항시각의 의미

원본은 기존 통합연구 패키지의 `vessels_all_nonGT_2020_2025.pkl.gz`입니다. 별도 수집이나 합성 기항은 추가하지 않았습니다.

- 입력 파생자료 56,791건: 이미 체류시간 6시간 초과·유효 작업량 등으로 선별된 자료입니다.
- 기상 완전관측·유효한 수치·기상 시점 조건을 만족한 검색 인덱스 48,155건.
- 최종 작업량·접안/출항 기준시각·기상·작업률 등 검색에 필요한 열만 추렸습니다. 선박명·선사·원본 선박 식별자는 없습니다.
- 사례 ID는 추출본에서 새로 부여한 순번이며 실제 선박 ID가 아닙니다.
- 이 단계에서 P99 꼬리를 추가 제거하지 않았습니다. 위험 평가에서는 기존 P99 플래그 제외 대상 151건을 보존했습니다.
- 이전 전처리에서 제외된 6시간 이하 기항이나 원자료 오류 행을 복원한 것은 아닙니다.

**BCT·BNCT·HPNT·PNC·PNIT는 원자료에 실제 출항시각이 없고 예정 출항시각 대체를 사용했습니다.** BPTC_G는 실제 출항이며, BPT_S는 대부분 실제 출항입니다. 따라서 작업률은 원자료의 출항 기준을 사용한 파생지표이고 실제 시간별 장비 생산성·작업중단 기록과 같지 않습니다. 신항 화면에는 이 설명을 눈에 보이게 표시합니다.

## 3. 유사 기항 검색

### 검색 대상과 순서

1. 같은 터미널만 검색합니다.
2. 접안시각과 원자료 계산용 출항시각이 모두 조회 시각보다 앞선 기록만 남깁니다.
3. 입력 조건의 거리를 계산합니다.
4. 거리 상한 이내 사례만 가까운 순서로 최대 20·30·50건을 보여줍니다.

거리 순위에는 작업률·체류시간·효율저하 사건 여부를 사용하지 않습니다. 좋은 결과만 골라 검색하는 기능도 아닙니다. 원자료 계산용 출항시각이 지났다고 실제 완료가 확인된 것은 아니며, 그 기록이 당시 시스템에 전달된 시각도 검증할 수 없습니다.

### 비교 요소

| 요소 | 가중치 | 처리 |
| --- | ---: | --- |
| 작업량 | 0.30 | log 변환, 터미널별 IQR 척도 |
| 풍속 | 0.25 | 터미널별 IQR 척도 |
| 파고 | 0.20 | 터미널별 IQR 척도 |
| 시정 | 0.15 | log(1+시정 m), IQR 척도 |
| 월 | 0.05 | 12월과 1월을 가깝게 처리 |
| 시간대 | 0.05 | 23시와 0시를 가깝게 처리 |

최종 거리는 가중 평균제곱의 제곱근입니다. 수치형 척도는 **2020–2022년** 자료 21,084건에서 고정했으므로 2023년 이전 조회는 제한합니다. 거리 1.0은 검색 편의를 위한 기본 상한이며 유사도 100%나 검증된 정확도 기준이 아닙니다. 엄격 0.75·기본 1.0·확장 1.25를 선택할 수 있습니다.

### 화면에 표시하는 결과

- 후보 수, 거리 상한을 충족한 수, 실제 표시한 수
- 작업률 박스·점 분포, 중앙값, 중간 50% 범위
- 체류시간 중앙값
- 가까운 사례의 작업량·기상·작업률·시간·출항시각 출처
- 전체 검색 결과 CSV와 입력별 거리 성분

과거 사례의 분포는 새 기항의 예측구간이 아닙니다. 사례가 적으면 그 수를 그대로 보여주며, 먼 기록으로 요청 건수를 채우지 않습니다.

### 실제 확인한 기본 예시

BCT / 2027-11-20 10시 / 풍속 6m/s / 파고 1.2m / 시정 5,000m / 작업량 396:

- 같은 터미널의 과거 후보 2,777건
- 거리 1.0 이내 **6건**
- 기록 작업률 중앙값 **31.98/h**
- 원자료 기준 체류시간 중앙값 **14.50시간**

‘관측이 많은 날씨 예시’를 누르면 BCT의 2023년 기상 중앙값을 화면 눈금에 맞춘 풍속 1.8m/s·파고 0.4m·시정 39,500m로 바뀝니다. 날짜와 작업량을 유지한 이 조건에서는 거리 기준 충족 1,834건 중 가까운 30건을 표시합니다.

## 4. 큰 효율저하 위험의 사건 정의

```text
기록 작업률 = 최종 작업량 / 원자료 기준 체류시간
사건 = 기록 작업률 < 평온 기준 중앙 작업률 × 0.90
```

10%는 이번 기능을 위한 설계 기준입니다. 기존 BCT 강풍 −10.74% 결과를 경보 임계값으로 가져오지 않았습니다. 정확히 10% 저하한 값은 사건에 포함하지 않고, **10%를 초과해 낮은 값**을 사건으로 정의했습니다.

평온 기준 중앙 작업률은 2020–2022년 평온 표본에 학습한 CatBoost Quantile(0.5) 모형으로 정했습니다. log 작업률의 중앙값을 학습하고 지수 변환합니다. 기준모형에는 터미널·최종 작업량·월·요일·시각을 사용합니다. 최종 작업량이 필요한 이 계산은 **사후 평가 기준을 만드는 단계**입니다.

위험 분류모형에는 다음 **7개**만 입력합니다.

```text
terminal, month, weekday, berth_hour, wind, wave, vis_10m
```

최종 작업량·Shift 비율·혼잡도·완료 후 체류시간·출항시 날씨·전체 체류 중 기상·GT는 위험모델 입력에서 제외했습니다. 따라서 작업량이나 혼잡도만 바꾸면 새 위험 확률은 달라지지 않습니다. 이 기능은 기존 평균 작업률 모델과 다른 입력과 목표를 가집니다.

기준모형의 오차, 이후 숙련·선박 구성·운영정책 변화도 사건에 반영됩니다. 확률을 **기상 때문에 효율이 떨어질 확률**, 안전사고 또는 실제 작업중단 확률로 읽을 수 없습니다.

## 5. 시간순 학습·보정·평가

| 단계 | 기간 | 표본 | BCT 표본 |
| --- | --- | ---: | ---: |
| 기준모형 후보 | 2020–2022 | 21,084 | 268 |
| 평온 기준모형 학습 | 2020–2022 | 14,895 | 202 |
| 위험 분류모형 학습 | 2023 | 9,648 | 984 |
| sigmoid 확률 보정 | 2024 | 9,602 | 1,090 |
| 이후 연도 후향평가 | 2025 | 7,815 | 435 |

각 기간의 계산용 출항시각이 다음 기간 경계를 넘는 행을 제외했습니다. 평온 기준의 풍속·파고 P90 및 시정 P10도 2020–2022년 자료에서 새로 계산했습니다. 기존 2020–2024년 기상 cutoff를 기준학습에 재사용하지 않았습니다.

분류기는 가중치 없는 Logloss로 2023년에 학습했습니다. 2024년에 sigmoid 보정 기울기와 절편을 구하고, 같은 해 보정확률의 80분위수를 검토선으로 정했습니다. 이 검토선은 **31.03%**이며, 2024년 상위 20% 경계입니다. 2025년 실제 검토 비중은 29.24%여서 모든 시점에 정확히 20%를 고르는 기준은 아닙니다.

2025년 결과를 학습·보정·검토선 조정에 쓰지 않았습니다. 다만 2025년은 이전 프로젝트 분석에서 이미 살펴본 연도이므로 전혀 보지 않았던 신규 현장 시험이 아니라 **시간순 후향 평가**입니다. 이 고정모형으로 2025년 이전 시점의 당시 예측을 제공하지 않습니다.

## 6. 실제 성능과 현재 한계

Brier는 확률오차이므로 작을수록 좋습니다. ROC-AUC·AP는 순위 구분 성능이며 정확도 퍼센트가 아닙니다.

| 모델 | ROC-AUC | AP | Brier |
| --- | ---: | ---: | ---: |
| weather_calibrated | 0.5925 | 0.2652 | 0.16232 |
| calendar_no_weather | 0.5931 | 0.2581 | 0.16279 |
| constant_2024_rate | 0.5000 | 0.2023 | 0.16184 |
| terminal_2024_rate | 0.6169 | 0.2647 | 0.15683 |

새 기상 포함 모델은 터미널별 과거 발생률 기준보다 Brier가 더 크고 ROC-AUC가 더 낮아, 비교 기준보다 유리하지 않았습니다. 기상을 뺀 같은 학습 절차의 모델과 비교해도 큰 차이를 입증하지 못했습니다. 이 평가로 기존 악천후의 관측 연관성을 부정하거나 인과효과를 추정할 수는 없지만, **개별 기항의 저하 위험을 잘 순위화하는 기능은 아직 검증되지 않았다**고 해석해야 합니다.

검토선에서 전체 정밀도는 27.40%, 재현율은 39.60%입니다. 운영에 사용할 경보 기준으로 검증된 수치가 아니며, 화면에서도 ‘낮음/안전’이라는 초록 신호를 사용하지 않습니다.

### 터미널별 평가

| 터미널 | n | 사건비율 | ROC-AUC | 새 모델 Brier | 터미널별 발생률 기준 Brier |
| --- | ---: | ---: | ---: | ---: | ---: |
| BCT | 435 | 15.86% | 0.4425 | 0.13615 | 0.13600 |
| BNCT | 450 | 10.00% | 0.4746 | 0.09407 | 0.09103 |
| BPTC_G | 1,489 | 8.33% | 0.5879 | 0.08208 | 0.07686 |
| BPT_S | 4,162 | 21.79% | 0.5536 | 0.17853 | 0.17519 |
| HPNT | 381 | 18.11% | 0.3829 | 0.15592 | 0.15014 |
| PNC | 584 | 41.10% | 0.6136 | 0.24900 | 0.24232 |
| PNIT | 314 | 40.45% | 0.4325 | 0.30858 | 0.26513 |

특히 BCT의 기준모형은 개장 초기 평온 202건에 의존합니다. BCT AUC 0.4425는 현재 위험 순위가 유효하다는 근거가 아닙니다. 화면의 해당 터미널 성능과 참고용 상태를 확률 바로 근처에 표시했습니다.

### 자료지원도와 판단 보류

2023년 분류학습 표본만 사용해 같은 터미널의 풍속·파고·log(1+시정)을 IQR로 표준화합니다. 세 요소의 RMS 거리 1 이내 사례가 20건 이상이고, 각 기상이 해당 터미널 학습 관측범위 안일 때만 확률을 표시합니다. 이 20건 기준은 표시 정책이며 통계적 신뢰수준 보장이 아닙니다.

- 기본 BCT 복합기상 조건은 가까운 학습 표본 **2건**이어서 판단 보류입니다.
- 관측이 많은 날씨 예시는 지원 표본 **764건**, 모형 출력 **13.74%**입니다. 이 값도 BCT의 낮은 검증 성능을 함께 읽어야 합니다.
- 2025년 7,815건 중 7,731건(98.93%)이 표시 정책을 통과했습니다.
- 통과 표본의 AUC 0.5908, Brier 0.16172, 터미널별 발생률 기준 Brier 0.15622로 성능 개선은 여전히 확인되지 않았습니다.

전체 평가와 표시 정책을 통과한 평가를 각각 저장했습니다. 관측범위를 벗어나는 조건은 회색 ‘판단 보류’로 표시합니다.

## 7. 구현·검증 이력

- 기존 평균 예측의 BCT 기본 합산값 약 58.580/h, SHAP 재구성, 모델 B −10.74%, 운영학습 p=0.794/0.910을 다시 확인했습니다.
- 새 검색에서 같은 터미널·과거 시점·거리 상한을 확인했습니다. 결과 작업률·체류시간을 바꿔도 순위가 바뀌지 않습니다.
- 위험 입력의 작업량·혼잡·GT·동시접안 척수 비의존성을 확인했습니다.
- 시정 m→10m 단위 변환과 UTC/KST 동치를 확인했습니다.
- 별도 CatBoost 로드와 수동 sigmoid 계산이 앱 확률과 일치했습니다.
- 2023년 이전 검색, 2025년 이전 위험, 시정 0, 극단 기상, 근거 부족을 오류 없이 처리했습니다.
- Streamlit AppTest에서 기존 AI 조건 가져오기, 사례↔위험 이동, 다른 메뉴 경유 후 조건 보존과 새 예시 버튼을 확인했습니다.
- 사례 인덱스 재생성 결과는 기존 동봉 CSV.gz·metadata.json과 바이트 단위로 일치했습니다.

실제 브라우저 수동 시연이나 외부 Cloud 배포를 완료했다고 주장하지 않습니다. 제공하는 HTML은 Streamlit의 실제 출력에서 만든 **입력이 고정된 미리보기**입니다. 메뉴·상세 근거·그래프 확인은 가능하고, 새 입력 재계산은 Streamlit 앱에서 수행합니다.
