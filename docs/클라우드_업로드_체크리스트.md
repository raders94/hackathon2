# PORTaI v7 · 적용 범위와 실행 점검

## 이번 버전의 자료 범위

이번 ZIP은 **비공개 검토·실행용**입니다. `assets/case_search/case_index.csv.gz`에는 검색에 필요한 기항별 접안시각·계산용 출항시각·작업량·기상·결과 지표가 있습니다. 선박명은 제거했지만 집계자료만 있는 패키지는 아닙니다. 원본 연구자료의 외부 공개 제한을 유지합니다.

따라서 이전 공개 앱에 이 ZIP을 통째로 덮어쓰는 방식은 적용하지 않습니다. 이번 작업에서는 외부 업로드나 공개 배포를 하지 않았습니다. 허용된 비공개 실행 환경에서는 README의 설치 절차로 바로 실행할 수 있습니다.

## 로컬 또는 허용된 비공개 앱에 적용

1. 기존 앱을 백업하고 ZIP을 압축 해제합니다.
2. 최상위 `app.py`, `requirements.txt`, `src/`, `assets/`, `.streamlit/`를 같은 경로에 복사합니다.
3. `assets/case_search/`, `assets/risk/` 두 새 폴더를 빠뜨리지 않습니다.
4. Python 3.12 환경에서 `pip install -r requirements.txt` 후 `streamlit run app.py`를 실행합니다.
5. 메뉴 9개와 새 기능 2개가 나타나는지 확인합니다.

## 확인할 동작

- `check_release.py`가 기존 모델 수치와 새 기능 검증을 모두 통과한다.
- 유사 기항 기본 BCT 복합기상 조건에서 가까운 사례 6건과 소표본 안내가 나온다.
- ‘관측이 많은 날씨 예시’를 누르면 사례와 위험 결과가 재계산된다.
- 위험모델의 검증 성능 부족 안내, 해당 터미널 성능, 세 가지 확률오차 비교가 보인다.
- 시정 0, 과도한 풍속, 자료가 적은 조건에서 오류 대신 안내·판단 보류가 표시된다.
- 사례 → 위험 → 다른 메뉴 → 사례로 이동해도 공통 조건이 유지된다.
- 미래 날짜는 실제 예보가 아닌 입력 시나리오로 표시된다.

원본 전체 pickle·API 비밀키·외부 계정정보는 이 패키지에 포함하지 않았습니다. 공개 서비스용으로 바꾸려면 사례 인덱스를 공개 가능한 집계 또는 허가된 서버 조회 방식으로 별도 설계해야 합니다.
