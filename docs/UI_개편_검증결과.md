# PORTaI v6 직관형 화면 · 검증 결과

## 변경 범위

대시보드를 7개 분야로 나눴습니다. 첫 화면은 세 가지 핵심 결과를 비례 막대로 제시하고, 각 분야는 결론·대표 그래프·상세 근거 순서로 구성합니다. 예측값, 관측 분석, 실제자료 평가, 사용자 가정은 서로 다른 화면과 배지로 구분합니다.

학습모형과 `assets/`의 기존 분석 결과 파일은 수정하지 않았습니다. 대시보드 표현과 탐색 구조를 변경했습니다.

## 확인한 항목

| 점검 | 결과 |
|---|---|
| Python 소스 구문 및 모듈 로드 | 통과 |
| 기존 `check_release.py` 모델·수치·SHAP 검산 | 통과 |
| 7개 메뉴 기본 화면의 Streamlit 실행 | 예외 없음 |
| 악천후 영향: 3개 기상요인 × 2개 노출 구간 | 6개 조건 통과 |
| 터미널 현황: 2020·2025·전체 기간 | 3개 조건 통과 |
| 운영학습: 7개 터미널 선택 | 7개 조건 통과 |
| 예측 검증: 전체 + 7개 터미널 선택 | 8개 조건 통과 |
| 위 24개 조건의 메인 그래프 값과 원본 CSV 대조 | 일치 |
| 위 24개 조건의 NaN/Inf 표시·비유한 차트값·잘못된 신뢰구간 길이 | 없음 |
| WAPE 가중 계산·평가 포함/제외 누적막대 합계 | 계산식 일치·합계 100% |
| 예측의 평온 프리셋, 복합 악천후 복귀 | 결과 재계산 확인 |
| 예측 화면 → 개선 계획 → 예측 화면 | 마지막 예측조건 유지 확인 |
| GT 역사모형 선택 후 미래 날짜 전환 | GT 사용 자동 해제 확인 |
| 개선 계획의 회복 100% 가정 | 정상 실행 |
| 평온과 같은 예측에서 회복 격차 0 처리 | 중립 안내 확인 |

기본 BCT 시나리오의 선박당 예상 작업률은 약 29.29/h, 평온 기준 대비 변화율은 약 −6.91%입니다. 모델 B의 BCT 강풍 4–6회 결과 −10.74%는 별도 분석 결과이며 두 수치를 합산하지 않습니다.

## 검증 환경과 범위

- Python 3.12, Streamlit 1.67.0, Plotly 6.9.0, CatBoost 1.2.10에서 확인했습니다.
- 화면 실행과 입력 변경은 Streamlit `AppTest`로 확인했습니다.
- 첫 화면의 HTML/CSS 구성은 별도 문서 렌더러로 점검했습니다. 실제 브라우저의 전체 화면·모바일 렌더링 검사를 대체하지 않습니다.
- 이 환경에서는 브라우저 시작에 필요한 소켓 생성이 제한되어 실제 Chromium 구동 검증을 완료하지 못했습니다.
- 실제 GitHub 업로드나 Streamlit Cloud 배포는 이번 작업에 포함되지 않았습니다.

## 동봉 미리보기

별도로 제공한 HTML은 앱의 기본 조건에서 생성한 실제 텍스트와 그래프를 담은 읽기용 화면입니다. 메뉴 이동과 상세 펼치기는 가능하지만 날씨 입력을 바꿔 모델을 재계산하지는 않습니다. 실제 입력 변경은 실행 패키지의 `app.py`를 사용합니다.
