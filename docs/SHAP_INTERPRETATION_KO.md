# CatBoost SHAP 예측 설명서

## 구현 방식

- `CatBoostRegressor.get_feature_importance(Pool(...), type='ShapValues')` 이용. `shap` Python 패키지는 별도 설치하지 않습니다.
- 기존 머신러닝 예측 타깃이 **`log(선박별 총작업량/전체 접안시간)`**이므로 SHAP 값은 `log(작업단위/h)` 단위입니다.
- `SHAP 기준 log 예측 + 모든 변수 SHAP 값 합 = 현재 예측 log 작업률`이고, 결과는 `exp(...)`로 원래 작업률 단위로 바꿉니다.
- `100×(exp(SHAP값)−1)`는 **해당 변수의 단독 배수 환산**일 뿐, 여러 변수의 백분율을 단순 합산할 수 없습니다.
- SHAP 기준은 **모든 학습 데이터 분포**로 계산한 기준값이므로, 화면 상단의 **월별 평온조건 기준**과 다릅니다.

## 예시: 2027년 11월 20일 BCT 시나리오

선택한 예: 풍속 6.0m/s, 파고 1.2m, 시정 5,000m, 혼잡도 상(접안 유입 2척/6시간), 대표 작업량 396단위, 동시접안 2척 가정.

- 선박별 AI 예상 평균 작업률 **29.29 작업단위/h**
- 터미널 합산 가정 **58.58 작업단위/h**, 평온기상 기준 대비 **−6.91%**
- 모델 전체 학습분포 SHAP 기준 예측 **약 41.92 작업단위/h**
- 작업량의 SHAP: **−0.262 log** (절대값 기준 가장 큼)
- 풍속 SHAP: **−0.0365 log**; 파고 SHAP: **−0.0264 log**; 혼잡 SHAP: **−0.0200 log**
- 이 기여도는 모델이 학습한 **연관성에 따른 예측 분해**입니다. 실제 강풍 때문에 얼마가 감소했는지, 운영 노하우의 효과가 무엇인지를 입증하는 인과분석이 아닙니다.

## '평온 대비 SHAP 차이' 읽는 법

- 현재 기상과 월별 평온 기준 기상의 SHAP 값을 **각각** 계산한 뒤 차이를 취합니다.
- 모든 변수의 **SHAP log 차이 합**은 `log(현재 예측 / 평온 예측)`와 일치합니다.
- 날씨 세 변수만 바꿨더라도 **모델의 변수 상호작용** 때문에 작업량·터미널 등 고정 변수의 SHAP 기여도도 달라질 수 있습니다.
- 따라서 이 표를 `날씨의 실제 영향=날씨 변수 SHAP 차이 합`으로 해석하면 안 됩니다.

## 대시보드에서 확인할 기능

`01 AI 즉시 예측` → 선택된 예측 아래 **SHAP 설명** → `전체 변수` 또는 `기상·혼잡 변수 확대` → 항목별 CSV 저장.

더 자세한 2025년 외부검증은 `05 SHAP · 악천후별 모델 검증` 탭을 확인합니다.
