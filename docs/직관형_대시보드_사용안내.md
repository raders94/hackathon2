# PORTaI 직관형 대시보드 사용안내

> **v7 안내:** ‘유사 기항’과 ‘효율저하 위험’ 메뉴가 추가됐습니다. 새 기능·성능·비공개 실행 범위는 [v7 기능·검증 설명](v7_기능추가_검증.md)과 최상위 README를 먼저 확인하세요. 아래는 기존 일곱 화면의 사용 설명입니다.

## 이번 화면 개편의 목적

“분야별로 딱 구분되고, 대충 봐도 어느 결과인지 알 수 있게” 하는 것이 이번 개편의 기준입니다. 큰 숫자만 늘리지 않고 **막대 길이로 차이를, 제한된 색으로 상태를 구분**하도록 구성했습니다.

첫 화면은 핵심 결과를 모으고, 왼쪽 메뉴는 분야를 나눕니다. 각 분야에서는 **결론 한 문장 → 핵심 수치와 그림 → 펼쳐보는 근거** 순서로 읽습니다. 기존 분석값과 학습모형은 유지했습니다.

## 처음 볼 때의 순서

1. **한눈에 보기**에서 기상 영향·예측 검증·운영 변화의 핵심 결과를 확인합니다.
2. 궁금한 카드의 바로가기 또는 왼쪽 분야 메뉴를 선택합니다.
3. 맨 위 결론과 대표 그림을 보고, 조건을 바꾸면 무엇이 달라지는지 확인합니다.
4. 표본·신뢰구간·계산 방법이 필요할 때만 아래의 상세 영역을 펼칩니다.

분야별 화면을 나눴으므로, 하나의 긴 페이지에서 모든 그래프를 찾을 필요가 없습니다.

## 분야별로 무엇을 보여주나요?

| 메뉴 | 이 화면이 답하는 질문 | 먼저 볼 부분 |
| --- | --- | --- |
| **한눈에 보기** | 그래서 무엇을 알게 됐나? | 핵심 결과 카드와 크기 비교 그림 |
| **AI 예측** | 이 조건이면 작업률이 얼마나 달라지나? | 현재 조건과 평온 기준의 예측 비교 |
| **악천후 영향** | 운영조건을 고려해도 날씨와 효율 차이가 관련되나? | 모델 B의 7터미널 가로막대 |
| **터미널 현황** | 어떤 터미널을 얼마나 관측했나? | 기항 수와 중앙 작업률의 두 그림 |
| **운영학습** | 시간이 지나며 평온 효율과 강풍 대응이 각각 달라졌나? | 두 질문을 나란히 보여주는 그림 |
| **예측 검증** | 새 연도의 예측오차는 어느 정도인가? | 기상별 상대오차와 평가 표본 범위 |
| **개선 계획** | 어느 수준을 목표로 하고 무엇을 검증해야 하나? | 가정 회복 목표와 90일 준비 단계 |

SHAP는 **AI 예측의 ‘예측이 나온 이유’**로 확인합니다. 모델 B의 별도 예측력 실험과 잔차모형 SHAP는 **예측 검증**의 상세 영역에 있습니다.

## 색과 크기는 이렇게 읽으세요

### 1. 같은 그림 안에서 길이를 비교합니다

막대는 해당 지표의 크기를 나타냅니다. 예를 들어 터미널 현황의 기항 수 막대는 길수록 관측 건수가 많습니다. 기항 수와 작업률은 단위가 다르므로 두 그림의 길이를 서로 비교하지 않습니다.

첫 화면에서도 **각 카드 안의 비교 기준은 같지만, 카드끼리는 지표와 눈금이 다릅니다.** 숫자와 단위는 그림을 보조하도록 함께 표시했습니다.

### 2. 색의 뜻은 그림의 범례에 따라 읽습니다

| 화면 | 색의 의미 |
| --- | --- |
| 악천후 영향 | 주황: 유의한 감소 · 청록: 유의한 증가 · 회색: 차이 불확실 |
| 터미널 현황 | 파랑: 기항 표본 규모 · 청록: 보정 전 중앙 작업률 |
| 예측 검증의 표본 범위 | 평가에 포함된 자료와 제외된 자료를 색으로 구분 |
| 개선 계획의 목표 그림 | 청록: 현재 예측 · 노랑: 가정 회복분 · 옅은 회색: 평온 기준까지 남은 차이 |

색만으로 결론을 정하지 않도록 **‘차이 불확실’, ‘사용자 가정’, 비교 기준과 단위**를 글자로도 표시했습니다. 회색 결과는 “영향이 없다”는 뜻이 아닙니다.

### 3. 가는 선의 의미를 구분합니다

- **악천후 영향:** 95% 신뢰구간입니다. 추정치의 불확실성을 보여줍니다.
- **터미널 현황의 분포 상세:** 25~75% 사분위 범위입니다. 실제 관측값 가운데 50%가 놓인 범위입니다.

둘은 다른 종류의 범위이므로 같은 뜻으로 읽지 않습니다.

## 대표 결과를 읽는 예시

### 악천후 영향: BCT 강풍 4–6회

기본 선택은 **강풍 · 첫 6시간 중 4–6회 vs 0회**입니다. 모델 B의 BCT 조정 작업효율 차이는 **−10.74%**입니다. 첫 화면의 기준 100과 약 89.3 비교 그림은 이 비율을 시각화한 것입니다.

이 수치는 작업량·선박 크기·운영조건 등을 고려한 관측자료의 연관성입니다. 강풍 때문에 정확히 10.74%가 손실됐다는 인과적 결론은 아닙니다. 관측 횟수는 연속 강풍 지속시간이나 장비 안전정지 기준과도 다릅니다.

근거: `assets/modelb_weather_residual_effects.csv`

### 운영학습: 평온 효율과 악천후 대응을 따로 봅니다

BCT의 평온조건 작업효율은 2024년이 2022년보다 **18.35% 높게 추정**됐습니다. 그러나 강풍 대응의 유의한 연간 개선은 확인되지 않았습니다. 두 결과를 한 문장으로 합쳐 “악천후 대응 학습이 개선됐다”고 읽지 않도록 그림을 분리했습니다.

근거: `assets/learning_calm_2024_vs_2022.csv`, `assets/learning_annual_slopes.csv`

### 예측 검증: 오차 막대는 낮을수록 좋습니다

2025년 전체 검증의 상대오차(WAPE)는 약 **15.63%**입니다. P95 이상 조건은 **16.43%**, P90 미만은 **15.45%**로 약 **0.98%p 차이**입니다. 오차율은 정확도와 다릅니다. R² 0.825도 “정확도 82.5%”라는 뜻이 아닙니다.

기상 관측이 모두 갖춰진 표본을 평가했으므로, 옆의 평가 표본 범위도 함께 확인합니다. 터미널별 표본 구성과 누락이 달라 오차만으로 운영 성과의 순위를 매기지 않습니다.

근거: `assets/model_2025_test_metrics.csv`, `assets/validation_severity_2025.csv`, `assets/validation_availability_2025.csv`

## 기존 앱을 새 화면으로 바꾸기

1. 허용된 비공개 실행 환경에서 ZIP을 압축 해제합니다.
2. 기존 저장소에 `app.py`, `src/`, `assets/`, `.streamlit/config.toml`, `requirements.txt`, `packages.txt`를 포함한 **패키지 내용 전체**를 같은 경로로 반영합니다.
3. `src/`의 새 페이지 파일을 빠뜨리지 않았는지 확인합니다. `app.py`만 교체하면 새 화면을 불러올 수 없습니다.
4. 기존 Streamlit 앱이 바라보는 저장소·브랜치를 갱신합니다. 시작 파일은 `app.py`입니다.
5. 반영 후 한눈에 보기, 분야 이동, 예측 입력 변경, 상세 펼치기를 확인합니다.

v7에는 기항별 검색 인덱스가 추가됐습니다. 이 버전은 비공개 실행용이며, 기존 공개 앱에 그대로 업로드하는 절차는 적용하지 않습니다. 실제 Cloud 업로드·배포는 수행하지 않았습니다.

Windows 로컬 실행 명령은 [README](../README.md)에 있습니다. `check_release.py`로 핵심 수치를 검산할 수 있으며, 화면 실행검사는 별도 결과문서를 참조하세요.
