# PORTaI 유사 기항 검색 인덱스

기항별 연구자료에서 검색에 필요한 최소 열을 추린 자료입니다. 선박명·원본 선박 ID는 포함하지 않으며 `case_id`는 이 추출본에 새로 부여한 순번입니다.

## 검색 기준

- 같은 터미널의 사례만 검색합니다.
- 기준시각보다 접안시각과 원자료 계산용 출항시각이 모두 이전인 사례만 후보로 삼습니다.
- **원자료 출항기준에는 예정 출항 대체가 포함됩니다.** 계산용 출항시각이 지났다고 실제 작업 완료를 확인한 것은 아닙니다. `departure_source`를 함께 읽어야 합니다.
- 접안 후 체류시간이 6시간을 넘고, 풍속·파고·시정이 관측된 기항만 있습니다. 추가 P99 제거는 하지 않았습니다. 이 범위 밖 기항의 대표성을 주장하지 않습니다.
- 작업량과 시정은 양수, 풍속·파고는 0 이상인 유한값을 보존했습니다. 풍속·파고 0은 가능한 평온 관측이므로 제거하지 않았습니다.

## 거리

거리에는 `log(작업량)`, 풍속, 파고, `log1p(시정 m)`, 월·시간대의 순환 차이만 사용합니다. 결과값인 체류시간·작업률, Shift, GT, 최근 6시간 접안 유입은 포함하지 않습니다.

수치형 차이는 터미널별 **2020–2022년 자료의 IQR**로 나누며, 가중 평균제곱의 제곱근을 사용합니다. 월·시간은 순환 좌표의 두 성분을 하나의 그룹 거리로 처리하므로 두 번 가중하지 않습니다. 가중치 합은 1입니다. 정확한 가중치·척도·추출 규모는 `metadata.json`에 있습니다.

척도 계산에는 접안이 2020-01-01 이상이고 계산용 출항이 2023-01-01 미만인 자료만 사용했습니다. 따라서 **2023년 이전 시점의 검색은 지원하지 않습니다.**

기본 거리 상한 1.0은 검색의 휴리스틱 기준이며 검증된 확률이나 정확도 기준이 아닙니다. 상한 안의 사례가 부족하면 그 수만 반환하고 먼 사례로 채우지 않습니다. `matched_count`는 거리 상한 안의 전체 사례 수, `returned_count`는 요청한 상위 k개까지 실제 표시한 수입니다.

## 해석

이 검색은 과거 관측과의 유사성을 보여주는 기능입니다. 결과가 좋은 과거 사례의 운영조치나 그 조치의 인과효과를 알 수는 없습니다. 최종 작업량으로 구성된 연구자료이므로 접안 전 서비스에 쓰려면 계획 작업량과 변수의 당시 가용성을 별도 검증해야 합니다. 2025년 일부 기상은 선박 이벤트 시각 중심 기록으로 표본 대표성이 제한됩니다.

이 인덱스에는 기항별 시각·작업량이 포함됩니다. 공개 배포용 집계자료만 담았던 이전 패키지와 자료 범위가 다릅니다.
