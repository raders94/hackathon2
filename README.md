# PORTaI v7 · 유사 기항 검색과 효율저하 위험

**직관형 대시보드에 ‘유사 기항’과 ‘효율저하 위험’ 두 화면을 추가한 실행 패키지입니다.** 기존 평균 작업률 예측·SHAP·모델 B·운영학습 분석을 유지하고, 기항별 자료를 이용한 검색과 별도 위험 분류모델을 연결했습니다.

**이번 ZIP은 비공개 검토·실행용입니다.** 새 사례 인덱스에는 선박명 없이도 기항별 시각과 작업량이 들어 있습니다. 원본 연구 패키지가 지정한 외부 공개 제한을 유지합니다. 이전 집계자료 중심 패키지와 달라졌으므로 공개 저장소나 공개 앱에 그대로 올리지 마세요. 실제 외부 업로드·배포는 수행하지 않았습니다.

## 추가된 두 기능

| 기능 | 화면에서 확인하는 결과 | 처리 방식 |
| --- | --- | --- |
| **유사 기항** | 가까운 과거 사례 수, 작업률 분포·중앙값, 체류시간, 실제 기록 표와 CSV | 같은 터미널의 이전 기록만 대상으로 입력 조건 거리를 계산; 결과 작업률은 검색 순위에서 제외 |
| **효율저하 위험** | 기준 작업률보다 10% 넘게 낮을 참고용 예측확률, 자료지원도, 해당 터미널의 검증 성능 | 2023년 별도 분류학습 → 2024년 확률 보정 → 2025년 후향 평가 |

두 화면은 조건을 공유합니다. **AI 예측 조건 가져오기**로 기존 평균 예측의 조건을 불러올 수 있고, **관측이 많은 날씨 예시**로 2023년 학습 기상의 중앙값을 화면 눈금에 맞춰 입력할 수 있습니다.

자료가 적으면 유사 사례를 억지로 채우지 않습니다. 위험모델도 해당 터미널의 학습 관측범위를 벗어나거나 가까운 학습 기상이 20건 미만이면 **판단 보류**를 표시합니다.

## 위험모델의 실제 검증 결과

| 2025년 후향 평가 | 값 |
| --- | ---: |
| 평가 기항 | 7,815건 |
| 정의한 효율저하 사건 | 1,581건, 20.23% |
| ROC-AUC | 0.5925 |
| Average precision (AP) | 0.2652 |
| 새 모델 Brier 확률오차 | 0.16232 |
| 2024년 전체 발생률을 적용한 기준 Brier | 0.16184 |
| 2024년 터미널별 발생률을 적용한 기준 Brier | 0.15683 |

**Brier는 작을수록 좋습니다. 새 모델은 단순 기준보다 확률오차가 개선되지 않았으므로 ‘검증 단계의 참고 예측’으로 표시합니다.** 특히 BCT의 2025년 435건 AUC는 0.4425로 위험 순서를 잘 구분한다고 볼 수 없습니다. 낮은 출력값을 ‘안전’이나 ‘낮은 실제 위험’으로 표시하지 않습니다.

지원 조건을 충족해 실제 확률 표시가 가능한 평가 기항은 7,731건(98.93%)입니다. 이 집단에서도 Brier 0.16172로 터미널별 기준 0.15622보다 개선되지 않았습니다. 모델·보정·검토선은 이 2025년 결과로 재조정하지 않았습니다.

## 화면 구성

1. **한눈에 보기** — 핵심 연구 결과와 세 가지 AI 기능 바로가기
2. **AI 예측** — 예상 평균 작업률, 평온 조건 비교, SHAP
3. **유사 기항** — 비슷한 과거 기항 검색과 결과 분포
4. **효율저하 위험** — 별도 위험 분류모델과 검증 상태
5. **악천후 영향** — 모델 B 기상 영향과 터미널 비교
6. **터미널 현황** — 기항 규모·작업률·기상 분포
7. **운영학습** — 평온 효율 변화와 강풍 대응 변화
8. **예측 검증** — 기존 평균 작업률 모델의 2025년 성능
9. **개선 계획** — 가정 회복 목표와 현장 검증 준비

## Windows에서 실행

Python 3.12가 설치된 PC에서 압축을 풀고 **RUN_LOCAL_WINDOWS.bat**를 실행하세요. 별도 LLM API 키나 검색 서비스 계정은 필요하지 않습니다. 최초 패키지 설치 후 두 기능은 동봉 자료와 모델을 사용합니다.

직접 실행하려면 `app.py`가 있는 폴더에서 다음 명령을 사용합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Linux/macOS:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

기존 비공개 로컬 앱에 적용할 때는 ZIP의 **전체 내용**을 같은 경로에 덮어씁니다. `src/`뿐 아니라 새 `assets/case_search/`와 `assets/risk/`를 모두 복사해야 합니다. 공개 중인 앱에는 먼저 데이터 공개 범위와 접근제어를 별도로 정해야 합니다.

## 바로 시연하기

1. **유사 기항**을 엽니다. 기본 BCT 복합기상 조건에서는 가까운 사례 **6건**만 나오며 소표본 안내가 표시됩니다.
2. **관측이 많은 날씨 예시**를 누르면 같은 날짜·작업량에서 풍속·파고·시정이 바뀌고 검색 결과가 다시 계산됩니다.
3. **같은 조건의 효율저하 위험 보기**를 누릅니다. 충분한 자료가 있을 때 참고용 확률과 검증 결과를 확인합니다.
4. 풍속을 극단적으로 높이면 학습범위·자료 부족 안내와 **판단 보류**가 나타납니다.

기본 복합 악천후 조건에서 위험 확률이 보이지 않는 것은 오류가 아닙니다. BCT의 해당 조건과 가까운 2023년 학습 기항이 **2건**이어서 표시를 제한합니다.

## 지표와 적용 범위

- 작업률은 총작업량을 접안 후 출항 기준까지의 체류시간으로 나눈 **기항 단위 파생지표**입니다. 실제 크레인 시간당 Moves/h가 아닙니다.
- 원자료는 체류시간 **6시간 초과** 등의 조건으로 선별돼 있습니다. 모든 입항선박에 대한 검증이 아닙니다.
- BCT·BNCT·HPNT·PNC·PNIT는 실제 출항시각이 없고 예정 출항시각으로 대체했습니다. 새 화면에서 출처를 명시합니다.
- 검색 작업량은 과거 최종 작업량과 비교합니다. 계획 작업량을 이용하는 접안 전 검색의 성능은 별도 확인이 필요합니다.
- 위험모델 입력은 터미널·월·요일·접안시각·풍속·파고·시정 7개입니다. 최종 작업량은 사후 사건 기준 보정에만 쓰며 위험모델의 예측 입력에는 넣지 않습니다.
- 날짜·날씨는 사용자가 지정하는 시나리오입니다. 실시간 예보나 입항정보가 자동 연결되지 않습니다.
- 모델 B, SHAP, 새 위험 분류는 서로 다른 질문에 답합니다. 새 확률은 ‘악천후 때문에 손실이 생길 확률’이나 자동화 효과가 아닙니다.

모델은 이미 학습되어 있어 앱 실행 시 재학습할 필요가 없습니다. 위험모델 재현은 기존 통합연구 패키지의 `vessels_all_nonGT_2020_2025.pkl.gz`를 별도로 지정합니다.
